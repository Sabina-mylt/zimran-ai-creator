# Sabina Myltykbay — AI Creator, тестовое задание

Сайт с результатами: ролик Reyes Lawn Care (часть 2) и анализ двух креативов Coursiv (часть 1).

## Как поменять текст на сайте

1. Откройте сайт с `?edit` в конце адреса, например `https://<ник>.github.io/ai-creator-test/?edit`.
2. Нажмите на любой текст и исправьте его. В этом режиме все раскрывающиеся пункты открыты.
3. Нажмите «Скачать index.html».
4. Замените этим файлом `index.html` в папке репозитория и нажмите Commit to main, затем Push origin в GitHub Desktop.

Через минуту изменения появятся на сайте. Режим редактирования виден только тому, кто открыл ссылку с `?edit`.
